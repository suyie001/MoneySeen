# moneyseen_app

Flutter client for MoneySeen, targeting Web, iOS, and Android from one codebase.

The client is local-first: statement parsing, rules, reports, and the primary
ledger database remain on device. The Dart Frog API is used for model-backed
classification and future account services.

```bash
flutter run
```

See the repository [development guide](../../docs/development.md).
